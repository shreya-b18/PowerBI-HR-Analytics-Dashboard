# PowerBI-HR-Analytics-Dashboard

Objective: To analyze HR data and identify the key factors influencing employee attrition using interactive Power BI visualizations and DAX measures.

Tools & Technologies: 1) Power BI Desktop
                      2) Power Query
                      3) DAX (Data Analysis Expressions)
                      4) Excel (Dataset)

Visualizations Included:
The dashboard contains interactive visuals such as-
1) Attrition by Age
2) Attrition by Salary Slab
3) Attrition by Education
4) Attrition by Job Roles
5) Attrition by Gender
6) Employee Satisfaction Table – A detailed table representing different department's employee satisfaction scores etc.

These visuals help HR teams identify high-risk employee groups and areas requiring attention.

Files Included:
HR Analytics Dashboard-PowerBI Project.pbix – Power BI report
HR Analytics Dataset.xlsx – Dataset
Screenshots – Dashboard image

Features:
* Cleaned and transformed raw HR data using Power Query
* Built calculated measures using DAX (e.g., Attrition Rate, Avg Salary)
* Designed a user-friendly and interactive dashboard
* Provided insights helpful for retention planning and HR decision-making

Conclusion:
This HR Analytics Dashboard provides actionable insights into employee attrition patterns, helping organizations make data-driven decisions to improve retention and workforce stability.
